1. Problem Statement & Physical Parameters

The objective of this investigation is to simulate the internal laminar flow of liquid water through a circular pipe from a uniform slug velocity profile at the inlet, through the hydrodynamic entrance (developing) region, to the fully developed Hagen-Poiseuille parabolic profile.

In accordance with assignment requirements:

  • The inlet velocity Uin is set equal to the last two digits of the student's roll number: $U_{in} = 67\\text{ m/s}$ (Roll No: 21BCE1067).
  • The pipe diameter D is specifically selected to guarantee that the flow remains strictly laminar (Re < 2300).
  • The pipe length L is chosen to demonstrate both the developing entrance length Le and a significant portion of the fully developed flow region ($L \\ge 1.6 L_e$).

1.1 Fluid Physical Properties (Water at $20^\\circ\\text{C}$)

Property Symbol Value Unit
Density $\\rho$ 998.2 $\\text{kg/m}^3$
Dynamic Viscosity $\\mu$ $1.003 \\times 10^{-3}$ $\\text{Pa}\\cdot\\text{s} \\; (\\text{N}\\cdot\\text{s/m}^2)$
Kinematic Viscosity $\\nu = \\mu / \\rho$ $1.0048 \\times 10^{-6}$ $\\text{m}^2/\\text{s}$

1.2 Pipe Diameter Sizing for Laminar Stability (Re = 1600)

For internal flow through a smooth circular pipe, the critical Reynolds number for transition to turbulence is $Re_{crit} \\approx 2300$. To ensure a stable, strictly laminar flow with high numerical fidelity, we select a target Reynolds number:

Re = \\frac{\\rho U_{in} D}{\\mu} = 1600 < 2300 \\quad \\text{(Laminar Regime)} (1)

Solving equation (1) for the pipe diameter D:

D = \\frac{Re \\cdot \\mu}{\\rho \\cdot U_{in}} = \\frac{1600 \\cdot 1.003 \\times 10^{-3}}{998.2 \\cdot 67} \\approx 2.3972 \\times 10^{-5}\\text{ m} = 23.972\\;\\mu\\text{m} (2)

The corresponding pipe radius is $R = D / 2 = 1.1986 \\times 10^{-5}\\text{ m} = 11.986\\;\\mu\\text{m}$. This microtube scale physically corresponds to modern microfluidic cooling channels, micro-nozzle injectors, and lab-on-a-chip systems.

1.3 Hydrodynamic Entrance Length (Le) & Total Pipe Length (L)

In laminar pipe flow, the boundary layers grow from the wall inward until they merge at the pipe centerline at distance Le. According to the empirical and theoretical boundary-layer correlation for laminar pipe flow:

L_e \\approx 0.06 \\cdot Re \\cdot D = 0.06 \\cdot 1600 \\cdot 2.3972 \\times 10^{-5}\\text{ m} \\approx 2.3013 \\times 10^{-3}\\text{ m} = 2.301\\text{ mm} (3)

To ensure the computational domain encompasses both the complete developing region ($0 \\le x \\le L_e$) and an extensive portion of fully developed flow, we set:

L = 1.6 \\cdot L_e = 1.6 \\cdot 2.3013\\text{ mm} \\approx 3.682\\text{ mm} (4)

2. Governing Equations & Boundary Conditions

The internal flow is governed by the 2D axisymmetric, steady, incompressible Navier-Stokes equations formulated in cylindrical coordinates $(x, r)$:

\\text{Continuity: } \\frac{\\partial u}{\\partial x} + \\frac{1}{r}\\frac{\\partial (r v)}{\\partial r} = 0 (5)
\\text{Axial Momentum: } u \\frac{\\partial u}{\\partial x} + v \\frac{\\partial u}{\\partial r} = -\\frac{1}{\\rho}\\frac{dP}{dx} + \\nu \\left( \\frac{\\partial^2 u}{\\partial r^2} + \\frac{1}{r}\\frac{\\partial u}{\\partial r} \\right) (6)
\\text{Radial Momentum: } \\frac{\\partial P}{\\partial r} \\approx 0 \\implies P = P(x) (7)

2.1 Boundary Conditions

  • Inlet Boundary (x = 0): Uniform slug flow: $u(0, r) = U_{in} = 67\\text{ m/s}$, v(0, r) = 0, P(0) = P0.
  • Pipe Wall Boundary (r = R): No-slip and impermeability: u(x, R) = 0, v(x, R) = 0.
  • Centerline Symmetry (r = 0): Zero shear and radial velocity: $\\left.\\frac{\\partial u}{\\partial r}\\right|_{r=0} = 0$, v(x, 0) = 0.
  • Fully Developed Outlet ($x \\ge L_e$): Invariant axial velocity: $\\frac{\\partial u}{\\partial x} = 0$.

2.2 Analytical Benchmark: Fully Developed Hagen-Poiseuille Flow

When the flow reaches the fully developed state (x > Le), exact integration of equation (6) yields the parabolic Hagen-Poiseuille velocity distribution:

u(r) = 2 U_{in} \\left[ 1 - \\left(\\frac{r}{R}\\right)^2 \\right] (8)

From equation (8), the peak centerline velocity is exactly double the inlet slug velocity:

u_c = u(0) = 2 \\cdot U_{in} = 2 \\cdot 67\\text{ m/s} = 134.0\\text{ m/s} (9)

The analytical fully developed pressure gradient and Darcy friction factor are:

\\frac{dP}{dx} = -\\frac{32 \\mu U_{in}}{D^2} = -\\frac{32 \\cdot 1.003 \\times 10^{-3} \\cdot 67}{(2.3972 \\times 10^{-5})^2} \\approx -3.742 \\times 10^9\\text{ Pa/m} = -3.742\\text{ MPa/mm} (10)
f = \\frac{64}{Re} = \\frac{64}{1600} = 0.0400 (11)

3. Multi-Tool Simulation Implementations

3.1 Python Finite-Difference TDMA Solver (`fluids/python/`)

A high-order 2D axisymmetric boundary layer solver was developed in Python utilizing a non-uniform staggered grid (Nr = 80 radial nodes clustered near the wall, Nx = 300 axial stations). The axial momentum equation is discretized using a semi-implicit marching scheme where the unknown axial pressure gradient $\\frac{dP}{dx}$ at each station is constrained by the integral continuity mass conservation:

\\int_0^R 2\\pi r u(x, r)\\,dr = \\pi R^2 U_{in} (12)

The resulting linear tridiagonal system is solved efficiently using the Thomas algorithm (Tridiagonal Matrix Algorithm - TDMA) with O(Nr) computational complexity per axial station.

3.2 ANSYS Fluent CFD Journal (`fluids/ansys/`)

An automated journal file `pipe_flow_fluent.jou` sets up a 2D planar axisymmetric domain in ANSYS Fluent:

  • Pressure-based coupled solver with steady laminar formulation.
  • Near-wall boundary layer inflation mesh with 15 prism layers ensuring y+ < 1.
  • Second-Order Upwind spatial discretization for momentum; PRESTO! scheme for pressure.
  • Convergence criteria set to 10-7 across continuity and axial velocity residuals.

3.3 COMSOL Multiphysics Model Script (`fluids/comsol/`)

A programmatic model script `pipe_flow_comsol.m` sets up the 2D axisymmetric Laminar Flow (spf) physics module with mapped quadrilateral boundary-layer meshing and PARDISO direct linear solver.
