INTERACTIVE ENGINEERING & AI SUITE

A unified web-deployable simulation environment implementing two advanced computational domains: Autonomous Robotics Path Planning with 6 AI search algorithms, and 2D Axisymmetric Computational Fluid Dynamics (CFD) for internal laminar pipe flow.

Artificial Intelligence

🤖 Smart Maze-Solving Robot

Simulate an autonomous 2D robot navigating intricate labyrinths, obstacle fields, and local minima traps.

  • 6 Search Algorithms: A* (Manhattan & Euclidean), BFS, DFS, UCS, Greedy Best-First
  • Kinematic 2D Robot: Directional headlights beam, sensor eyes, treads & antenna
  • Procedural Mazes: Recursive Backtracker, Prim's, Bottleneck, Spiral, Trap
  • Performance Benchmarks: Real-time node expansion wave & optimality metrics
Fluid Mechanics & CFD

🌊 Laminar Pipe Flow Simulation

Numerical solution of water flow through a circular pipe from uniform slug inlet through the developing entrance length to fully developed Hagen-Poiseuille flow.

  • Roll Number Velocity: Parameterized inlet velocity $U_{in}$ (e.g. 67 m/s)
  • Laminar Diameter: Auto-calculated microtube geometry for $Re = 1600 < 2300$
  • Developing & Developed: Hydrodynamic entrance length $L_e$ and pipe length $1.6 L_e$
  • High-Fidelity Colormap: 2D velocity field $u(x, r)$, radial profiles, and pressure drop
🚀 Instant 1-Click Deployment Guide

This web application is built with 100% client-side HTML5, CSS3, and JavaScript with zero backend dependencies. It can be deployed in seconds to:

• Vercel: Run vercel or push to GitHub and import repository.
• Netlify: Drag and drop this folder into Netlify Drop.
• GitHub Pages: Enable Pages in repo Settings pointing to root /.
• Local: Run python -m http.server 8000 or open index.html.
